## What

Display the [Pulumi][pulumi] project name, stack, logged-in user, and backend URL, or the active local context.

:::caution
By default, this requires a `pulumi` binary in your PATH and a `Pulumi.yaml` or `Pulumi.json` project file.
:::

## Options

| Name           | Type      | Default | Description                                                           |
| -------------- | :-------: | :-----: | --------------------------------------------------------------------- |
| `context_only` | `boolean` | `false` | Display the local context without a CLI or project.                   |
| `fetch_stack`  | `boolean` | `false` | Fetch the current stack name in project mode.                         |
| `fetch_about`  | `boolean` | `false` | Fetch the backend URL and user. Requires `fetch_stack` set to `true`. |

### Context-only mode

Set `context_only` to `true` to read the JSON `current` field from `$PULUMI_HOME/credentials.json`.
When `PULUMI_HOME` is unset or empty, the path is `$HOME/.pulumi/credentials.json`.
This mode needs neither the Pulumi CLI nor a project file and makes no CLI or cloud calls.
It ignores `fetch_stack` and `fetch_about`, populating only `.Context`.
The segment is disabled when the file is absent, empty, malformed, or has no non-whitespace string `current`.

```json
{
  "type": "pulumi",
  "style": "plain",
  "options": {
    "context_only": true
  }
}
```

:::caution
Debug logging redacts the contents of `credentials.json`. Context-only mode also omits decoder errors
that could contain credential values.
:::

## Template ([info][templates])

:::note default template

```template
\ue873 {{ .Stack }}{{if .User }} :: {{ .User }}@{{ end }}{{ if .URL }}{{ .URL }}{{ end }}
```

:::

In context-only mode, the default template is:

```template
 {{ .Context }}
```

### Properties

| Name       | Type     | Description                                           |
| ---------- | -------- | ----------------------------------------------------- |
| `.Name`    | `string` | The project name in project mode.                     |
| `.Stack`   | `string` | The current stack name when `fetch_stack` is enabled. |
| `.User`    | `string` | The logged-in user when `fetch_about` is enabled.     |
| `.URL`     | `string` | The backend URL when `fetch_about` is enabled.        |
| `.Context` | `string` | The `current` backend value in context-only mode.     |
